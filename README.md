食品标签审核 V1.4  技能包说明
========================================

一、这是什么
豆包办公（工作模式）的一个技能：上传预包装食品标签照片，先做全文无条件转录，
再按 GB 7718-2025、GB 28050-2025、《食品标识监督管理办法》（总局令第100号）
逐条审核，输出一份含 5 个工作表的 Excel 报告：
审核概览 / 不合格项清单 / 整改任务表 / 营养成分核对 / 核查底稿。

二、装到哪
解压后把 food-label-audit 整个文件夹放到：
  <豆包工作区>\agent_mode\workspace\.user_skills\
（和已有的其他技能目录并列）。重启会话后，技能列表里会出现
“食品标签审核 V1.4”，名称栏显示 food-label-audit（平台规范要求小写英文标识，
不要改文件夹名，改了会加载不了）。
没有 .user_skills 目录就自己新建一个，路径同上。

三、怎么用
新开一个会话，把标签照片（正面、背面、侧面、封口各一张）发上来，说一句
“审一下这个标签”。也可以直接勾选技能后发图。
包装最大表面面积量一下（正面长×宽，cm²）一起发，字号类判定才能出定量结论。
条码、二维码、喷码这类小区域，拍照时单独补一张近照，判得更准。

四、依赖
本技能的报告生成脚本需要 Python 3 和 openpyxl：
  python -m pip install openpyxl
知识部分（条款判定、识别、出结论）不依赖任何库，缺库时脚本会提示先装。
不需要联网，条款全部从本地 references 读取。

五、版本变更

V1.1（相对 V1.0）
1. 新增「必查清单」，逐项枚举；脚本校验覆盖度，漏查项自动补“【必查项未核查】”
   并在运行输出里点名。
2. 新增「引导词存在 ≠ 已标示」：印了“食品生产许可证号：”而冒号后空白，按未标示判缺失。
3. 新增「图案核查」，按 GB 7718-2025 问答第三十五条分三类判定。
4. 底稿补充 SC 空白情形、SC 缺失与 SC 不实的区分、图案四类情形。

V1.2（相对 V1.1）
1. 必查清单新增「商品条码与占位符」。
2. 新增「有图形 ≠ 有内容」：白框画一排等宽竖条＋“条码”二字、无 13 位数字行、
   无静区的，是设计稿占位，判“未完成”，不给符合。
3. 底稿补商品条码一节：条码非强制项、标示须符合 GB 12904、按《商品条码管理办法》注册。

V1.3（相对 V1.2）
1. 必查清单新增「质量等级与执行标准一致性」。
2. 新增「标了等级 ≠ 等级对」：看到“等级：XX”必须回查标准现行版本的等级名称。
3. 明确分级：少字/多字属瑕疵；用废止等级名、同一包装两种等级属一般。
4. 底稿补 GB/T 1355 换版案例（1986 版四级 → 2021 版精制粉/标准粉/普通粉）。

V1.4（相对 V1.3）
1. **新增“全文无条件转录”步骤（第 2.1 节）**：判定前先把标签上每一段文字逐字抄进
   JSON 的 transcript 块，按区域分组；不省略、不合并、不纠正、不判断。
   转录完做两道差集：转录→清单（每段字都要有落点，没落点就补判）、
   清单→转录（每项都要找得到字段，找不到判缺失）。
2. 脚本新增 verify_transcript()：缺 transcript 或条目过少，在运行输出里报
   “未做全文转录”，防止又回到“想到才查”。
3. 必查清单由 24 项扩到 **30 项**，新增 6 项：
   ⑥ 净含量字符高度（按净含量分档查最小字高，须同时满足《定量包装商品计量监督管理办法》）
   ⑬ 日期标示方式与实际可读性（“见×××喷码”指向是否明确、喷码是否真存在、到期日能否复算）
   ⑯ 配料定量标示（名称/图案/文字特别强调某配料时是否标含量或配比）
   ⑱ 营养表格式（表头、列名、表格线、每份基准、项目顺序）
   ㉒ 辐照食品标示
   ㉓ 转基因食品标示
4. 底稿补：辐照/转基因标示口径、日期“见×××”的落地核查细则、营养表格式 5 点检查。

六、已知边界
- 这是文件审查，不替代检测和实物测量：字符高度、真实含量记“无法判定/需实测”。
- 三份文件 2027-03-16 施行，本技能用于改版前预审；判现行在售产品是否违规仍按 2011 版。
- 营养数值由本地脚本复算（修约、0 界限、NRV%、能量加和），模型只照抄标签数字。
- 等级判定依赖执行标准的现行版本；标准换版后须同步更新 references/gb7718-2025.md 第 9 节。
- 全文转录靠人（模型）逐字抄，图片糊、压盖、反光处记【不可读】，不许猜。
